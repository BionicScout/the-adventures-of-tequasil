## Runtime
Runtime is one of Automaton [[Gorzod Montane|Gorzod]] set up at [[Gorzods Smoke and Steel|Gorzod's Smoke & Steel]]. Runtime is a Automaton specialized on doing a quality check on all sold items. He does this by examining each product and run a series of test on them. As the day goes on and he loses energy, he starts to repeat tests. One time Gorzod found Runtime check the spin on a revolver by saying "Test Cycle 457 Complete. Mechanism in perfect order. On to Test Cycle 458". This is where he gets his name run time.
